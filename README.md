# Software Engineering Portfolio

Koyu temalı, modern ve animasyonlu bir yazılım mühendisliği portfolyo sitesi.

## Özellikler

- GitHub Pages ile yayınlanabilir statik yapı
- HTML, Tailwind CSS CDN ve vanilla JavaScript
- Responsive tasarım ve mobil menü
- Hakkımda, teknoloji yığını, projeler, eğitim ve iletişim bölümleri
- JavaScript içindeki veri nesnesinden dinamik içerik üretimi
- Kategori bazlı proje filtreleme
- Scroll tabanlı giriş animasyonları
- Harici build veya backend gerektirmez

## Teknolojiler

Java · Spring Boot · PostgreSQL · Docker · Python · C

## Kullanım

1. Repository'yi GitHub Pages için yayınlayın.
2. `app.js` içindeki `portfolio` nesnesinden isim, e-posta, sosyal medya, proje ve eğitim bilgilerini güncelleyin.
3. Değişiklikleri GitHub'a gönderin.

GitHub Pages ayarı için **Settings → Pages → Deploy from a branch** seçeneğinden `main` branch ve `/ (root)` klasörünü seçin.

## Dosya yapısı

```text
index.html   # Sayfa yapısı
styles.css   # Tema, responsive stiller ve animasyonlar
app.js       # Portfolyo verileri ve etkileşimler
```
